# 01 — Python Basics

Three files, meant to be used in this order.

## 1. `python_basics_simple.py` — guided walkthrough

Read it top to bottom, then run it:

```bash
python3 python_basics_simple.py
```

Every section prints its own output, so you can match each line of code to what
it produces. Ten sections: printing, variables, math, strings, lists,
`if`/`else`, loops, functions, dictionaries, and `input()`. Five practice tasks
at the end.

## 2. `python_basics_exercises.py` — 20 exercises

Fill in each stub, then run it. A built-in checker prints PASS/FAIL per
exercise and a score (starts at 0/20):

```bash
python3 python_basics_exercises.py
```

Covers types, strings, conditionals, loops, lists, dicts and sets,
comprehensions, closures, exceptions, and writing a class.

## 3. `python_basics_solutions.py` — reference answers

Same checker, all filled in — run it to see 20/20 passing. Try each exercise
yourself before looking.

No dependencies; any Python 3.6+ interpreter works.
